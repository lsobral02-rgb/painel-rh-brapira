Guia de exportação — arquivos necessários

📋 Entrevistas de Desligamento

Exportar do módulo de Entrevistas de Desligamento. Deve conter CPF, Data do desligamento, respostas das perguntas e campo "Colaborador se recusou…"

👤 Dados dos Colaboradores

Exportar o relatório completo de colaboradores. Necessário para mapear CPF → Nome → Setor → Cargo.

🔗 Hierarquia

Exportar a planilha de hierarquia com Nome do líder e Nome do liderado. Necessário para a visão por gestor.

🗓 Cadência recomendada

Exporte toda sexta-feira para ter o painel pronto para as reuniões de segunda-feira.
